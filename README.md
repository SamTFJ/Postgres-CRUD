# Postgres-CRUD
- This is a simple application that uses Streamlit and PostgresSQL to manage and store a python CRUD data.

- The .env.template shows the required credentials to run the project and connect to supabase. Follow the instructions and fill the missing fields.

### To install the requirements use:
```
make install
```

### To run the application use:
```
make run
```

### To clean the logs use:
```
make clean
```

### To test the DB connection use:
```
make test 
```

### To create tables and update views:
```
make init-db
```
